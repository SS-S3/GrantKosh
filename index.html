    About this project

    GrantKosh is a plain static site: one JSON file of programs and a few hundred lines of JavaScript. There is no account, tracking, or paywall. The data is released under CC BY 4.0 and the code under MIT, so you can fork it, embed it, or build your own tools on top.

    Always confirm on the official portal before applying. Schemes change amounts, reopen and close without notice. Entries marked Needs check haven't been verified against the source by a maintainer yet.

    GrantKosh is not affiliated with any government body.
